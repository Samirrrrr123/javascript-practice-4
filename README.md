# Практическая работа №4

Список товаров на Vue. Данные загружаются с DummyJSON.

Фильтры: название без учёта регистра, категория, цена и рейтинг.
Получение данных и фильтрация находятся в `src/services/products.js`.
Категории и границы цены берутся из загруженных товаров.
Цена округляется до шага 50, оба ползунка стоят в середине.

## Запуск

Нужен Node.js 22.12 или новее.

```bash
npm install
npm run dev
```

Сборка: `npm run build`.

Ветка `main` — код, `pages` — сборка сайта.
